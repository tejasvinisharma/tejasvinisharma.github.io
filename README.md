# tejasvinisharma.github.io

My personal portfolio site, hosted on GitHub Pages.

**Live site:** [tejasvinisharma.github.io](https://tejasvinisharma.github.io)

## Status

In progress. Right now the site lists the projects I'm building and links to my LinkedIn and GitHub. Each project gets a card with a screenshot, a live demo and a link to its code once it's published.

## Built with

- HTML and CSS, in a single `index.html` with no framework and no build step
- Google Fonts (Poppins and Inter)
- GitHub Pages for hosting

## Design choices

- **Phones first.** The layout is written for small screens and widens at 720 px.
- **Accessible.** Buttons are at least 44 px tall, keyboard focus is clearly outlined, and the decorative shapes are hidden from screen readers.
- **Fast.** No JavaScript, one HTML file, and two web fonts.

## Run it locally

```bash
git clone https://github.com/tejasvinisharma/tejasvinisharma.github.io.git
cd tejasvinisharma.github.io
```

Then open `index.html` in a browser. There is nothing to install.
